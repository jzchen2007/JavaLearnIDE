Java 学习 IDE v1.0.0

面向大学 Java 初学者的轻量级开发环境，基于 Electron + Monaco Editor + JDK javac 构建。

功能：一键编译运行（外部独立终端）、关键字中文词典、Tab 自动补全、实时错误波浪线、编译错误中文化、代码统计。
