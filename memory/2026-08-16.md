
## v2.4.0 多题单管理

用户需求：题单支持多个（储存在电脑中）、改题单名称、题单题目支持删除。

### 实现
- 数据模型 `settings.leetcodeLists = [{ id, name, problems }]` + `leetcodeActiveId`；旧单题单 `leetcodeList` 在 init 时自动迁移为「默认题单」。
- 侧边栏题单栏：下拉切换（`#lc-lists` select）+ 新建（+）/重命名（内联 input 行）/删除题单 三个 mini-btn。
- 每题右侧悬停显示删除按钮（`.lc-del`，用 `ICON.svg('close')`），点击删除题目（`deleteLcProblem`）。
- 导入到当前选中题单（`getActiveList()`），持久化 `persistLists()`。

### 教训
- 渲染动态列表时，删除按钮事件用「父容器委托 + closest('.lc-del') 判断」避免点删除也触发打开题目；或用 stopPropagation。
- Electron 渲染进程无 `window.prompt()`（会抛错），重命名用内联 input 行（Enter 保存 / Esc 取消）替代。
